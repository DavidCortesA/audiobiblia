# Audio Biblia · sitio web

Next.js 16 (App Router, Cache Components) para Vercel. Ver la sección **Página web** del README principal.

```bash
npm install
npm run dev          # http://localhost:3000
```

Variables de entorno: copia `.env.example` a `.env.local`. Los datos los envía la Mac con `./ab web-sync` (o `./ab web-sync --local` en desarrollo).
